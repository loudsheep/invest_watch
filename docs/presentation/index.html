HackNation 2026 - zadanie UKNF

Problem

  • Reklamy instrumentów finansowych rozpraszają się po stronach firm, blogach i social mediach.
  • Ręczny nadzór nie nadąża: tysiące treści, zmieniających się w czasie.
  • Trzy pytania nadzorcze: kto reklamuje cudzymi rękami, czy ryzyko jest pokazane uczciwie, kto doradza bez zezwolenia.

InvestWatch zbiera treści, ocenia je modelami open source i oddaje analitykowi gotowe, udokumentowane findingi.

Rozwiązanie: trzy moduły, jeden obiekt

M1 Finfluencerzy

Linki afiliacyjne, kody promo, brak oznaczenia reklamy. Powiązanie z firmą z rejestru KNF/ESMA.

M2 Ryzyko

18 kryteriów z podstawą prawną (art. 44 rozp. 2017/565): czcionka, kontrast, ukrycie, responsywność, prognozy, aprobata KNF.

M3 Shadow advisory

Oferty doradztwa bez zezwolenia, klony firm i domeny lookalike, wiek domeny (RDAP).

Wszystkie moduły produkują ten sam finding, agregowany w case wokół podmiotu.

Pipeline AI: dwa poziomy

  • Klasyfikator (ms na CPU): embeddingi multilingual-e5 + skalibrowana głowica, score steruje progiem.
  • LLM (tylko kandydaci): Gemma przez Ollamę, wynik JSON walidowany Pydantic, cache po hash + model + prompt.
  • Reguły M2 w YAML: zmiana wymogów UKNF to edycja jednego pliku.
  • Cały stos on-premise, zero płatnych API.

M2: wizualna wyraźność ostrzeżenia

  • Screenshot + computed styles z DOM: rozmiar czcionki, kontrast WCAG, stopka/legal, przezroczystość.
  • Render na tablecie i telefonie: ucięty lub zbyt mały tekst.
  • Dominacja wyników historycznych, informacja za kliknięciem, aprobata KNF jako argument bezpieczeństwa.
  • Wykrycie usunięcia ostrzeżenia przy ponownym crawlu.

Każde kryterium w UI ma detektor, wagę i podstawę prawną.

Dowody i raport dla nadzoru

  • Zabezpieczenie dowodów: HTML, screenshot, computed styles, SHA-256 i znacznik czasu w Garage.
  • Pakiet dowodów (ZIP + manifest) i raport PDF case'a z hashami.
  • Audit log: zmiany statusów, progów, retrainu i dostępu do dowodów.
  • Graf powiązań: finfluencer - firma - dokument - kod promo - domena.
  • Klaster kampanii: podobne treści po odległości wektorowej (pgvector).

Kalibracja i human-in-the-loop

  • Suwak progu per moduł: natychmiast zmienia FP i FN.
  • Precision / recall i krzywa PR na etykietach analityka.
  • Potwierdzenie lub odrzucenie findingu trafia do zbioru etykiet.
  • "Przetrenuj model" podbija wersję klasyfikatora.

Alerty wysokiego ryzyka w czasie rzeczywistym przez Socket.io, a "Skanuj URL teraz" pokazuje etapy pipeline'u na żywo.

Proces wytwarzania z asystentami AI

  • Spec-driven: CONCEPT.md + 21 ADR (MADR) zamiast ustnych ustaleń.
  • AGENTS.md / CLAUDE.md w repo i w każdym serwisie: konwencje, granice, Conventional Commits.
  • Cykl: spec → implementacja AI → testy → review AI → review człowieka → merge.
  • Bramki CI: ruff, eslint (no-console), pytest, pip-audit, npm audit, Trivy, gitleaks.

Roadmapa wdrożenia w UKNF

  • Teraz: MVP on-premise, jedna komenda, dane demonstracyjne.
  • Pilotaż: żywa synchronizacja rejestrów KNF/ESMA, OIDC (Keycloak), kolektory Facebook i Instagram za zgodą na sesję.
  • Produkcja: inferencja na GPU, Prometheus + Grafana, active learning na decyzjach analityków.
